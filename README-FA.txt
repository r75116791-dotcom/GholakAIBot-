پروژه اصلاح‌شده اولیه ربات قلک

این پوشه جایگزین نسخه قبلی است. فایل gradle/wrapper/gradle-wrapper.properties اضافه شده
و تنظیمات pluginManagement برای resolve مستقیم افزونه‌ها تنظیم شده است.

نکته مهم:
- این پروژه هنوز APK آماده نیست.
- کد تشخیص قلک‌ها از تصویر، پردازش زنده صفحه، محاسبه فیزیک/مسیر و تصمیم‌گیری خودکار
  هنوز پیاده‌سازی نشده است.
- سرویس دسترس‌پذیری فقط چارچوب آزمایشی دارد و هیچ حرکتی را خودکار اجرا نمی‌کند.
- فایل gradle-wrapper.properties به‌تنهایی شامل gradle-wrapper.jar و اسکریپت gradlew نیست؛
  در Code on the Go از گزینه ساخت/Gradle داخلی برنامه استفاده کن.
- نسخه Gradle wrapper پیشنهادی 8.9 و افزونه Android Gradle Plugin نسخه 8.7.3 است.
- اگر Code on the Go همچنان Gradle 9.6.1 را به اجبار اجرا کند، ممکن است لازم باشد
  تنظیم نسخه Gradle در خود برنامه تغییر کند یا از محیط ساخت سازگار استفاده شود.

روش باز کردن:
1) ZIP را در حافظه گوشی استخراج کن.
2) در Code on the Go گزینه Open from folder را بزن.
3) پوشه GholakAIBot-Fixed را انتخاب کن؛ همان پوشه‌ای که settings.gradle.kts در آن است.
4) اجازه بده وابستگی‌ها دانلود شوند؛ اینترنت پایدار لازم است.

ساخت آنلاین با GitHub Actions:
1) همه محتویات این پوشه را در یک repository جدید GitHub بارگذاری کن.
2) در repository به Actions برو.
3) workflow با نام Build Android APK را انتخاب و Run workflow را بزن.
4) پس از اتمام موفق، از بخش Artifacts فایل GholakAIBot-debug-apk را دانلود کن.
توجه: این خروجی فقط برنامه آزمایشی پایه است؛ هوش بازی هنوز پیاده‌سازی نشده است.
